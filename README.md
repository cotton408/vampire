# 솔안리 — 조금 수상한 우리들의 시골살이

HTML, CSS, JavaScript만 사용하는 반응형 캐릭터·스토리 소개 랜딩 페이지입니다. 빌드와 패키지 설치가 필요하지 않습니다. AI 채팅 서비스 자체는 포함하지 않습니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 웹 서버로 이 폴더를 실행하세요.

## GitHub Pages 배포

1. GitHub 저장소에 이 폴더 **안의 파일**을 올립니다. `index.html`, `styles.css`, `script.js`, `.nojekyll`이 저장소 루트에 있어야 합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 파일을 올린 브랜치(예: `main`)와 **/(root)**를 선택하고 저장합니다.
4. 배포가 완료되면 Pages 화면에 표시되는 주소로 접속합니다.

하위 경로에서도 작동하도록 CSS와 JS는 상대 경로를 사용합니다. 별도 API 키나 서버가 필요하지 않습니다. 실제 GitHub 배포는 저장소에서 진행해야 합니다.

## 구성 및 수정

- `index.html`: 이야기, 플레이 가이드, 마을 정보, 행사 소개
- `styles.css`: 반응형 레이아웃, 세로 그라데이션, 모달 페이드 애니메이션
- `script.js`: 등장인물 데이터, 상세 창, 오늘의 체크리스트
- 이미지: 모든 일러스트 영역은 의도적인 placeholder입니다. 메인 `.placeholder-scene`, 캐릭터 `.portrait`, 상세 `.modal-portrait`, 마을 `.village-placeholder` 영역을 이미지로 교체하세요. 캐릭터 카드 이미지는 `script.js`의 카드 생성 부분에서 수정합니다. 실제 이미지를 넣을 때 `alt` 텍스트도 함께 작성하세요.
- 폰트: Google Fonts의 **Jua**, **Gowun Dodum**을 사용합니다. 인터넷 연결이 없으면 시스템 sans-serif로 표시됩니다.
- 예시 대사: 프람벨·유나는 제공된 예문을 사용하고, 나머지 네 인물은 성격을 바탕으로 작성한 소개용 대사입니다.

## 인터랙션과 접근성

캐릭터 카드를 누르면 상세 내용이 페이드인되고, 닫기 버튼·Escape 키·창 바깥 클릭으로 페이드아웃됩니다. 네이티브 dialog로 초점을 창 안에 유지하고 닫은 뒤 원래 카드로 돌려줍니다. 동작 줄이기 설정을 존중하며 체크리스트 변경은 스크린리더에도 전달합니다. 체크 상태는 새로고침하면 초기화됩니다.
